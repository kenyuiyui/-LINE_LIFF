開始使用前，請先知道這些事

  • 需要自己申請 Groq API Key 才能使用（免費，見下方輸入框旁的教學連結）
  • API Key 會存在這台裝置的瀏覽器裡。如果這是公用或跟別人共用的裝置（例如公司電腦、借用的手機），請在下方「共用裝置」區塊清除資料，或使用完畢後手動清除，避免下一個使用者看到你的 Key 與筆記內容
  • 錄音轉成文字後，原始音檔不會被保留，只留文字卡片。如需留底請另外用手機錄音 App 同時錄一份
  • 轉寫過程會將這段音訊上傳到 Groq 的伺服器處理，語音內容不是完全留在你手機本機
  • 每 15 秒會自動切一段送出轉寫，句子剛好跨越切段點時可能被拆成兩張卡片，屬已知限制
  • 整理好的語音卡片會自動儲存在這台裝置的瀏覽器裡，就算不小心切出去、誤觸上一頁或重新整理，回來也找得回來；但這也代表若為共用裝置，請務必在使用完畢後於 API Key 卡片內點「清除本機資料」，避免下一位使用者看到你的內容
  • 發送功能有三種：「送回聊天室」直接存回你打開此頁面時所在的聊天室（僅限從 LINE 聊天室進入時可用，最推薦）；「LINE 好友選單」需要先登入 LINE 才能選對象發送；「手機分享」在 LINE 內開啟時會自動改走好友選單（LINE 內建瀏覽器對系統分享有限制）
  • 「查看共享筆記」是唯讀功能，只能讀取別人貼在共用 Google Sheet 裡的內容（可勾選多筆、與自己的語音卡片混合，一起生成摘要），不會寫回 Sheet；要把自己整理好的內容或生成好的摘要加進 Sheet，需使用「複製成 Sheet 貼上格式」／「存回 Sheet」按鈕複製後自行手動貼上

① 建立一份新的 Google Sheet

打開 sheets.new 直接建立一份空白表格（或用現有的既有表格也可以）。這份表格不需要任何標題列，每一格都直接存放一筆完整資料，從 A1 開始，往下一格一格填。

② 把整理好的內容複製貼上

在「筆記」或「摘要」分頁點「複製成 Sheet 貼上格式」（或摘要那邊的「存回 Sheet」），系統會問你要取什麼主題名稱，接著自動複製成一整包資料到剪貼簿。回到 Google Sheet：

  1. 點選 A1 儲存格
  2. 直接貼上（Ctrl+V 或長按貼上）
  3. 下一個人要貼，就點 A2；再下一筆就 A3，依此類推，永遠貼在下一個空白格

每一格看起來會是一長串英數字夾雜符號的文字（例如 {"label":"上半場逐字稿",...}），這是正常的——這份表格是設計給程式讀取的資料庫，不是給人閱讀的表格，不需要、也請不要手動整理成別的格式。

③ 設定分享權限，並取得連結

點右上角「共用」按鈕 → 「取得連結」，把權限改成：

✅ 「知道連結的使用者」→「檢視者」
這是本工具唯一需要的權限。任何拿到連結的人都能「讀取」內容，但沒有人（包括本工具）能修改或刪除表格。
❌ 請不要選「編輯者」
見下方「資安提醒」。

複製這個連結，貼到本工具的「共享」分頁輸入框，點「讀取」即可。

⚠️ 資安提醒：關於「連結可編輯」

本工具只會讀取資料，程式碼裡完全沒有寫入 Google Sheets 的功能，就算你把權限設成「編輯者」，本工具本身也不會、也沒有能力去修改你的表格。

但「連結可編輯」這個設定本身的風險，跟這個工具無關，而是 Google Sheets 本身的機制：一旦設成「知道連結的使用者」＋「編輯者」，代表任何拿到這個連結的人（不限於你邀請的協作者，只要連結被轉傳出去、被搜尋引擎索引到、或不小心分享錯地方）都能修改、刪除、甚至清空整份表格，不需要登入、不需要驗證身份。

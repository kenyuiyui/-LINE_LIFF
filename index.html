開始使用前，請先知道這些事

  • 需要自己申請 Groq API Key 才能使用（免費，見下方輸入框旁的教學連結）
  • API Key 會存在這台裝置的瀏覽器裡。如果這是公用或跟別人共用的裝置（例如公司電腦、借用的手機），請在下方「共用裝置」區塊清除資料，或使用完畢後手動清除，避免下一個使用者看到你的 Key 與筆記內容
  • 錄音轉成文字後，原始音檔不會被保留，只留文字卡片。如需留底請另外用手機錄音 App 同時錄一份
  • 轉寫過程會將這段音訊上傳到 Groq 的伺服器處理，語音內容不是完全留在你手機本機
  • 每 15 秒會自動切一段送出轉寫，句子剛好跨越切段點時可能被拆成兩張卡片，屬已知限制
  • 整理好的語音卡片會自動儲存在這台裝置的瀏覽器裡，就算不小心切出去、誤觸上一頁或重新整理，回來也找得回來；但這也代表若為共用裝置，請務必在使用完畢後於 API Key 卡片內點「清除本機資料」，避免下一位使用者看到你的內容
  • 發送功能有三種：「送回聊天室」直接存回你打開此頁面時所在的聊天室（僅限從 LINE 聊天室進入時可用，最推薦）；「LINE 好友選單」需要先登入 LINE 才能選對象發送；「手機分享」在 LINE 內開啟時會自動改走好友選單（LINE 內建瀏覽器對系統分享有限制）

這個工具只做「即時音轉文字」，錄音轉成文字後原始音檔就會被丟棄，不會留存也不會上傳保存，但轉寫過程會把這段語音上傳到 Groq 雲端伺服器處理。如果你需要留一份原始錄音備份，請另外用手機內建的錄音 App（語音備忘錄/錄音機）同時錄一份，兩者互相獨立。
這會清除目前這台裝置、這個瀏覽器裡儲存的：
  • 你填過的 Groq API Key
  • 「不用再提醒」的已讀記錄（下次會重新看到提示彈窗）
  • 登入跳轉前暫存的待發送文字（若有）
  • 目前尚未發送出去的語音卡片內容（卡片會自動即時儲存，方便誤觸返回或切換分頁時找回，但也代表清除時會一併被刪除，且無法復原）
⚠️ 這個工具清不到的地方：如果你曾經用「複製到剪貼簿」功能，筆記內容可能還留在系統剪貼簿裡（這是手機/瀏覽器本身的機制，網頁無法主動清除）。若這是共用裝置，建議額外複製一段無關文字覆蓋掉。

還沒有 Groq API Key？點這裡看申請教學
  1. 打開 console.groq.com/keys（會直接跳到 API Keys 頁面）
  2. 用 Google／GitHub／Email 任一種方式註冊登入（Email 註冊需要驗證信箱）
  3. 登入後點畫面上的「Create API Key」按鈕
  4. 隨便輸入一個名稱（例如「我的筆記」），送出
  5. 畫面會顯示一串以 gsk_ 開頭的金鑰——這串只會顯示這一次，記得先複製起來，離開頁面後就看不到了
  6. 回到這裡，把整串貼進上面的輸入框即可
